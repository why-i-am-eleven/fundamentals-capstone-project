# GitHub submission checklist

- [ ] Replace generic cover metadata with your own course/student details if required.
- [ ] Read the README and understand what is implemented versus proposed.
- [ ] Run the API locally and capture genuine screenshots if practical evidence is required.
- [ ] Run `terraform fmt -check`, `terraform validate`, and inspect `terraform plan`.
- [ ] Do not run `terraform apply` unless you have authorization and understand the costs.
- [ ] Ensure no credentials, `.env` files, state files, private keys or real personal data are committed.
- [ ] Create a public or private GitHub repository as instructed by your institution.
- [ ] Upload the extracted repository contents and verify the README renders.
- [ ] Add genuine implementation evidence only after completing the corresponding tests.
